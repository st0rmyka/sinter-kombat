# Sinter Kombat

2D verekedős játék (canvas). Karakterek: Renike, Ricsi, Cica, Vámpír Ági, Cigányricsi, Jézus.

## Futtatás

```bash
npm install
npm run dev
```

Böngészőben: a dev szerver `8080`-on.

## Backup

Ez a repo a 2026-09-05-ös teljes mentés (sprite-ok, SFX, forrás). `node_modules` nincs bent.

```bash
npm install
npm run dev
```
